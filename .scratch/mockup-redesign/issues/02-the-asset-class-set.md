# The Asset Class set

Type: grilling
State: open
Blocked by: none

## Question

The mockup has a **fixed** set: Cash, Stocks, Real estate, Crypto, Metals, Vehicles & other. Each has a fixed colour and its own Projection rate rule (Cash, Stocks and Real estate per Country; Crypto, Metals and Other shared). Today the defaults are Real Estate, Equity, Precious Metal, Cash and Crypto, plus User-created custom classes, with Target Allocation hanging off classes.

Decide:
- whether Asset Classes become a fixed enumeration (with custom classes removed);
- canonical names (Equity → Stocks? Precious Metal → Metals?) and the CONTEXT.md update. Note that "Equity" the mockup term means *asset value − linked loan*, which CONTEXT.md currently forbids in favour of "Projected Net Position". Settle that collision here;
- what each class's "noun" is (account / property / asset), which the mockup uses in labels and group headers.

**Blocked by:** none.
